1. O que é o TeOdonto Angola?

O TeOdonto Angola é um sistema de informação clínica desenvolvido especificamente para clínicas dentárias angolanas. Digitaliza todos os processos — do agendamento à faturação — eliminando papel, reduzindo erros e melhorando o atendimento ao paciente.

🦷

Gestão Clínica

Fichas de pacientes, histórico de tratamentos, triagens e planos de saúde oral.

📅

Agendamentos

Marcações online com lembretes automáticos por Email e WhatsApp 24h antes.

💰

Faturação

Emissão de faturas, controlo de pagamentos e relatórios financeiros em tempo real.

2. Funcionalidades Principais

🏥 Módulo Clínico & Atendimento

  • Registo completo de pacientes com foto, dados pessoais e QR Code único
  • Triagem clínica inteligente com nível de urgência, sintomas e fotos bucais
  • Histórico detalhado, planos de tratamento odontológicos e prescrições médicas
  • Gestão clínica de dentistas, especialidades e atribuição de pacientes
  • Exportação de relatórios clínicos e atestados em formato PDF profissional

⚙️ Módulo Administrativo & Governança

  • Dashboard com KPIs em tempo real e faturamento financeiro em Kwanzas (Kz)
  • Autenticação em 2 Etapas (2FA) via WhatsApp para Admin, Secretário e Dentista
  • Audit Log imutável: rastreio completo de acessos, alterações e cadastros
  • Relatórios do Sistema em 4 eixos (Visão Geral, Dentistas, Secretários e PDFs)
  • Notificações automáticas multicanal (WhatsApp e E-mail 24h antes)

3. Perfis de Utilizadores e Controlo de Acesso (RBAC)

👤

Paciente / Utente (Mobile & PWA)

Acesso ao histórico pessoal, agendamento de consultas, triagem prévia em casa com upload de fotos, e notificações sem complexidade de 2FA.

🔒

Protecção Especializada por Perfil

Políticas SQL RLS e 2FA via WhatsApp ativas para o staff clínico e administrativo, garantindo sigilo médico e facilidade de acesso aos utentes.

8. Tecnologia Utilizada

🖥️

Frontend — Interface

TypeScript + React Native
Linguagem principal de toda a aplicação. Permite detecção de erros antes de testar no telemóvel. Expo SDK facilita o build para Android, iOS e Web.

⚙️

Backend — Base de Dados

PostgreSQL + PL/pgSQL (SQL)
Supabase actua como servidor gerido. O SQL define as tabelas, regras de acesso (RLS), funções automáticas (triggers) e agendamentos (pg_cron).

☁️

Automações — Edge Functions

TypeScript (Deno runtime)
Funções serverless na cloud para envio de emails via Resend e mensagens WhatsApp. Sem servidor próprio para manter.

✅ 100% Open-Source: React Native (Meta/Facebook), PostgreSQL, Expo. Sem licenças proprietárias de custo elevado. Stack usada por empresas como Notion, GitHub e Twitter.

9. Segurança de Dados — Melhorias Implementadas

O sistema foi submetido a uma auditoria de segurança completa utilizando o Supabase Security Linter. Foram identificados e corrigidos 16 problemas de segurança classificados em 4 categorias:

🛡️ Problemas Corrigidos

Tipo de ProblemaStatus
View triagem com SECURITY DEFINER (ignorava RLS)✔ Corrigido
Tabela provincias sem RLS activo✔ Corrigido
9 funções SQL com search_path mutável (risco de injecção)✔ Corrigido
Funções admin acessíveis anonimamente pela API✔ Corrigido
Políticas RLS de escrita irrestrita em notificacoes✔ Corrigido
Bucket de imagens médicas com listagem pública✔ Corrigido
Extensão pg_net exposta no schema público✔ Corrigido

🔒 Mecanismos de Protecção Activos

  • Autenticação em 2 Etapas (2FA / MFA) — verificação via código de 6 dígitos no WhatsApp com fallback TOTP para Admin, Secretários e Dentistas.
  • JWT Authentication — cada utilizador tem um token assinado. Sem token válido, sem acesso.
  • Row Level Security (RLS) — políticas SQL garantem que cada utilizador só vê os seus próprios dados, mesmo que a API seja comprometida.
  • Audit Log Completo — rastreamento imutável de todas as ações sensíveis com operador, ação, timestamp e visualizador de metadados JSON.
  • REVOKE de permissões — funções administrativas não são acessíveis por utilizadores não autenticados.
  • Storage Policies — imagens médicas bucais acessíveis apenas pelo paciente dono ou staff autorizado.
