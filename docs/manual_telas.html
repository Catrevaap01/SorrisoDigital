Módulo de Autenticação

Telas responsáveis pelo acesso seguro ao sistema, gestão de contas e recuperação de credenciais.

🏠

1.1 — Tela de Boas-Vindas (Welcome Screen)

src/screens/auth/WelcomeScreen.tsx
Acessível por: Todos os utilizadores

É a primeira tela apresentada ao utilizador ao abrir o aplicativo. Funciona como um portal de acolhimento institucional moderno, incorporando um Carrossel Automático Dinâmico que transita suavemente a cada 10 segundos entre 5 ilustrações odontológicas de alta qualidade. Apresenta o logotipo oficial, a marca "Sorriso Digital / TeOdonto Angola" e o slogan "O seu sorriso em boas mãos" com acabamento em glassmorphism refinado.

Conduz o utilizador intuitivamente para a tela de Login através do botão "Começar" ou por toque nos indicadores visuais do carrossel.

Elementos da Interface

  • Carrossel inteligente com 5 slides odontológicos reais
  • Transição automática a cada 10 segundos com animação fluida
  • Indicadores interativos de paginação (dots) com estado ativo destacado
  • Gradiente protetor escuro sobre a imagem para contraste de texto perfeito
  • Ícone médico estilizado em container de vidro fosco (glassmorphism)
  • Título institucional com tipografia Inter moderna
  • Botão de ação principal "Começar" com ícone direcional

Fluxo de Navegação

  1. Utilizador abre a aplicação
  2. Carrossel inicia a exibição automática dos slides (10s por imagem)
  3. Utilizador pode aguardar ou interagir diretamente
  4. Ao clicar em "Começar", é direcionado para a Tela de Login
🔐

1.2 — Tela de Login com Verificação em Duas Etapas (2FA)

src/screens/auth/LoginScreen.tsx
Acessível por: Todos (com 2FA ativo para Staff)

Tela de autenticação principal da plataforma integrada ao Supabase Auth. Após validar as credenciais de e-mail e senha, o sistema direciona automaticamente pelo papel (RBAC): Paciente → Painel do Paciente; Dentista → Dashboard Clínico; Secretária → Dashboard Secretária; Administrador → Painel Executivo.

Autenticação em 2 Etapas (2FA via WhatsApp e TOTP): Obrigatória e ativa para cargos com acesso a dados confidenciais (Administrador, Secretário e Dentista). O utente comum (paciente) acede de forma ágil sem 2FA. O modal de desafio do código de 6 dígitos foi desenhado para ser 100% responsivo em qualquer dispositivo (Web, PWA e Mobile), com KeyboardAvoidingView e ScrollView que garantem que o teclado virtual nunca cubra os campos de digitação.

Funcionalidades & Experiência

  • Campo de e-mail com validação em tempo real
  • Campo de senha com alternador visual de visibilidade
  • Detecção automática de exigência de 2FA baseada no perfil
  • Modal responsivo de código de verificação via WhatsApp / TOTP
  • Suporte completo a telas pequenas em Web, PWA e Mobile sem corte
  • Recuperação de acesso via "Esqueceu a senha?"
  • Atalho para auto-cadastro de novos pacientes

Segurança Implementada

  • Sessões criptografadas com tokens JWT de alta segurança
  • 2FA direcionado para staff clínico e administrativo via WhatsApp
  • Proteção contra força bruta e cancelamento seguro de sessão
  • Prevenção de sobreposição por teclado em dispositivos móveis
  • Feedback claro de erros sem vazamento de metadados

1.3 — Tela de Cadastro (Register)

src/screens/auth/RegisterScreen.tsx
Acessível por: Paciente (auto-registo)

Tela de criação de conta para novos pacientes. Coleta as informações básicas necessárias para criar uma conta no sistema. Após o cadastro com sucesso, o utilizador é redirecionado para completar o seu perfil. Dentistas e secretários são criados diretamente pelo Administrador, não tendo acesso a esta tela.

Campos do Formulário

  • Nome completo
  • E-mail (validação de formato)
  • Senha (mínimo 6 caracteres)
  • Confirmar senha

Comportamento

  • Validações em tempo real nos campos
  • Criação de conta via Supabase Auth
  • Redirecionamento para "Completar Perfil" após cadastro
  • Link para retornar ao Login
🔑

1.4 — Recuperação de Senha

src/screens/auth/ForgotPasswordScreen.tsx
Acessível por: Todos

Permite ao utilizador solicitar a redefinição da senha através do e-mail cadastrado. O Supabase envia um e-mail com link seguro para redefinição. Esta tela é acessível pela plataforma móvel. Para o Admin, existe uma tela específica (AdminPasswordRecoveryScreen) dentro do painel administrativo para redefinir senhas de outros utilizadores.

Processo

  1. Utilizador insere o e-mail cadastrado
  2. Sistema envia e-mail de recuperação (Supabase)
  3. Utilizador recebe link e redefine senha
  4. Redireciona de volta ao Login

Elementos

  • Campo de e-mail com validação
  • Botão "Enviar Link"
  • Feedback de sucesso/erro via Toast
  • Link "Voltar ao Login"
👤

1.5 — Completar Perfil

src/screens/auth/CompleteProfileScreen.tsx
Acessível por: Novos Pacientes

Exibida após o primeiro login de um novo paciente. Coleta dados complementares obrigatórios para a criação do perfil completo no sistema. Enquanto o perfil não estiver completo, o utilizador não acede ao painel principal.

Dados Solicitados

  • Data de nascimento
  • Número de telefone
  • Género
  • Endereço / Bairro
  • Número do BI (Bilhete de Identidade)
  • Foto de perfil (opcional)

Após Completar

  • Dados guardados na tabela profiles do Supabase
  • Utilizador redirecionado para o Home do Paciente
  • Perfil marcado como completo no sistema

2.1 — Início — Painel do Paciente (Home Screen)

src/screens/paciente/HomeScreen.tsx
Paciente

Tela principal do paciente após autenticação. Funciona como um painel de controlo compacto, apresentando saudação personalizada com o nome do utilizador, acesso rápido às funcionalidades principais e um resumo das triagens mais recentes. Os dados são atualizados em tempo real via WebSocket (Supabase Realtime).

Secções da Tela

  • Header: Saudação "Olá, [Nome]! 👋" + avatar com iniciais
  • Ações Rápidas: 3 botões — Nova Triagem, Educação, Agendar
  • Dica do Dia: Card com dica aleatória de saúde bucal
  • Triagens Recentes: Lista das 3 últimas triagens com status
  • Aviso Legal: Lembrete de que o app não substitui consulta presencial

Status das Triagens

  • 🟡 Pendente: Aguardando resposta do dentista
  • 🔴 Urgente: Dor intensa ou prioridade alta
  • 🟢 Respondido: Dentista já respondeu com orientação

2.2 — Triagem Digital

src/screens/paciente/TriagemScreen.tsx
Paciente

É a funcionalidade mais inovadora do sistema. Permite ao paciente descrever o seu problema dentário de forma estruturada e enviar fotos dos dentes, sem precisar de ir fisicamente à clínica. O paciente interage com um odontograma SVG interativo (mapa dos 32 dentes) para indicar quais dentes apresentam dor ou problema, o que torna o processo muito mais preciso para o dentista que irá analisar.

Campos do Formulário de Triagem

  • Sintoma principal (seleção de lista)
  • Intensidade da dor (escala 0–10)
  • Duração do problema (ex.: "há 2 dias")
  • Localização no odontograma SVG interativo
  • Descrição livre do problema
  • Fotos dos dentes (galeria ou câmera)

Funcionalidades Técnicas

  • Odontograma SVG gerado programaticamente (React Native SVG)
  • Seleção de múltiplos dentes (arcada superior e inferior)
  • Upload de fotos via expo-image-picker
  • Armazenamento de imagens no Supabase Storage
  • Notificação em tempo real para o dentista responsável
📅

2.3 — Agendamento de Consulta

src/screens/paciente/AgendamentoScreen.tsx
Paciente

Permite ao paciente solicitar o agendamento de uma consulta diretamente pelo aplicativo. O pedido entra como "pendente" na fila de trabalho da secretária, que irá confirmar, atribuir um dentista e definir o horário definitivo. O paciente recebe notificação quando o agendamento é confirmado.

Dados Necessários

  • Tipo de consulta (Consulta Geral, Avaliação, Retorno, etc.)
  • Data pretendida
  • Período preferido (Manhã / Tarde)
  • Observações adicionais (campo livre)
  • Preferência de dentista (opcional)

Fluxo após Submissão

  1. Pedido enviado ao sistema com status "Pendente"
  2. Secretária recebe notificação no seu dashboard
  3. Secretária confirma e atribui dentista e hora
  4. Paciente recebe confirmação no app

src/screens/paciente/HistoricoScreen.tsx
Paciente

Exibe o histórico completo de todas as triagens realizadas pelo paciente. Cada item mostra o estado atual, a data, o sintoma principal e, se já respondida, uma pré-visualização da orientação do dentista. O paciente pode tocar em qualquer triagem para ver os detalhes completos.

Informações por Triagem

  • Data relativa ("há 2 horas", "ontem")

  • Nome do dentista que respondeu (se aplicável)
  • Orientação resumida do dentista

Funcionalidades

  • Lista completa com atualização em tempo real
  • Filtros por status (Todos, Pendente, Respondido)
  • Pull-to-refresh para recarregar dados
  • Toque para ver detalhes completos

Paciente

3.1 — Dashboard do Dentista

src/screens/dentista/DashboardScreen.tsx
Dentista

O painel central do dentista é a tela mais completa e rica em funcionalidades do módulo. Apresenta um resumo de toda a atividade clínica: triagens pendentes para resposta, agenda do dia, indicadores financeiros e documentos clínicos recentes. A interface adapta-se à especialidade registada (ex.: Ortodontia, Implantologia) com configurações visuais específicas (getEspecialidadeConfig).

Contadores e Indicadores (Cards de Topo)

  • Total de triagens recebidas
  • Triagens pendentes de resposta
  • Triagens urgentes (dor > 6 ou prioridade alta)
  • Tratamentos realizados (faturados)
  • Prescrições emitidas
  • Receita do período (em Kz)

Filtros e Ações da Lista

  • Filtros: Todos / Pendente / Urgente / Respondido / Realizados
  • Atualização em tempo real (Supabase Realtime)
  • Acesso à triagem com opção de responder
  • Exportação de documentos (PDF): Anamnese, Plano de Tratamento, Prescrição, Histórico
  • Pull-to-refresh para atualização manual

6.1 — Chat (Tela de Conversa)

src/screens/shared/ChatScreen.tsx
Paciente Dentista Secretária

Interface de chat em tempo real que permite comunicação direta entre os diferentes perfis de utilizadores (Paciente ↔ Dentista, Paciente ↔ Secretária). As mensagens são entregues instantaneamente via Supabase Realtime, sem necessidade de recarregar a tela. É a alternativa digital às chamadas telefónicas para comunicações clínicas rápidas.

Funcionalidades do Chat

  • Mensagens em tempo real (WebSocket)
  • Bolhas de mensagem diferenciadas (enviadas/recebidas)
  • Timestamp em cada mensagem
  • Indicador de estado da mensagem (enviado/lido)
  • Scroll automático para última mensagem
  • Campo de texto com botão de envio
  • Suporte a teclado (KeyboardAvoidingView)

Arquitetura Técnica

  • Tabela messages no Supabase com RLS (Row Level Security)
  • Subscription em tempo real por canal de conversa
  • Cada conversa tem um ID único (UUID)
  • Histórico persistente — mensagens não se perdem

Considerações Finais

O Sorriso Digital é composto por mais de 40 telas distribuídas por 4 módulos principais (Paciente, Dentista, Secretária e Administrador), mais um módulo transversal de comunicação. Toda a plataforma foi construída com React Native + Supabase, garantindo funcionamento nativo em iOS, Android e Web a partir de um único codebase.

A arquitetura orientada a roles (RBAC) garante que cada utilizador apenas acede ao que lhe compete, com todas as comunicações protegidas por autenticação JWT e Row Level Security (RLS) no Supabase.
